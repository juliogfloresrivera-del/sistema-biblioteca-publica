# Sistema de Gestión de Biblioteca Pública

Este proyecto es una aplicación web desarrollada para optimizar y automatizar los procesos de una biblioteca pública. Permite administrar el catálogo de libros, gestionar el registro de socios y controlar el flujo de préstamos y devoluciones de manera eficiente.

## Tecnologías Utilizadas

* Frontend: Angular (Interfaz responsiva con soporte para modo claro/oscuro)
* Backend: Java con Spring Boot
* Base de Datos: PostgreSQL (alojado en Supabase)
* Integraciones: API Factiliza (para consulta automática y validación de DNI)
